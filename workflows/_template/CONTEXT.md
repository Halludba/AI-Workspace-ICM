# Workflow: Template Workflow

## Purpose
Provide a domain-neutral scaffold for a reusable ICM workflow.

## Applicability
This template is not executable.
It exists only as a structural reference for workflows created in this repository or specialized clones.

## Workflow Inputs
Declare workflow-entry inputs in the specialized workflow.
Do not add live inputs to this template.

## Stage Sequence
1. `01-stage` - placeholder transformation stage.

## Context Dependencies
No profiles, skills, references, or config dependencies are selected by the template.

## Completion
A specialized workflow defines its own terminal completion criteria.
Run artifacts belong under `work/`, not here.
